<p>1.1.1 운영체제</p>
<ul>
<li>하드웨어 위에 설치되어 하드웨어 계층과 다른 소프트웨어 계층을 연결하는 소프트웨어 계층</li>
<li>컴퓨터 시스템 자원을 관리하고, 사용자가 컴퓨터를 사용할 수 있는 환경을 제공</li>
</ul>
<p>1.1.2 운영체제의 목적</p>
<ul>
<li>처리 능력 향상 : OS는 자원 관리를 통해 일정 시간 내에 시스템이 처리하는 일의 양을 향상시킴</li>
<li>반환 시간 단축 : 사용자가 시스템에 요청한 작업을 오나료할 때까지 소요되는 시간 단축</li>
<li>사용 가능도 향상 : 사용 가능도는 시스템 자원을 얼마나 빨리 제공할 수 있는가를 의미한다. OS는 사용자가 컴퓨터를 사용해야 할 때 자원을 즉시 사용할 수 있게 한다.</li>
<li>신뢰도 향상 : 신뢰도는 시스템이 주어진 문제를 정확하게 푸는지를 의미한다. OS는 입력 값에 대한 정확한 결과를 줄 수 있도록 신뢰도를 향상해야 한다.</li>
</ul>
<p>1.1.3 CPU와 메모리</p>
<ul>
<li>CPU(Central Processing Unit, 중앙 처리 장치 = 프로세서)는 '컴퓨터의 뇌' 역할을 하며, 컴퓨터에서 프로그램을 실행하는 데 필요한 연산을 처리하고 수행</li>
<li>메모리 : 데이터를 저장하기 위한 기억장치로, 휘발성 메모리인 주 기억장치와 비휘발성 메모리인 보조 기억장치가 있다.<blockquote>
<p>주 기억장치 : 메인 메모리를 의미하며 일반적으로 RAM을 가리킨다.
보조 기억장치 : SSD, HDD 등</p>
</blockquote>
</li>
</ul>
<p><img alt="" src="https://velog.velcdn.com/images/jojjong/post/bcd14be5-3fc5-4dfe-adc4-9c5b51a9d916/image.png" /></p>
<blockquote>
<p>레지스터 : CPU가 사용자 요청을 처리하는 데 필요한 데이터를 임시로 저장하는 기억장치. CPU 내부에 존재하며 접근 속도가 빠르다.
캐시 메모리 : CPU와 RAM 사이의 속도 차이를 해결하기 위한 기억장치. CPU 내부에 위치하며 접근 속도가 레지스터 다음으로 빠르다.
RAM : 컴퓨터에서 프로그램을 실행할 때 필요한 정보를 저장한다. CPU에서 접근 속도가 하드 디스크보다 빠르고, 휘발성 기억장치다. 
하드 디스크 : 사용자가 필요한 데이터와 프로그램을 저장하고, 비휘발성 기억장치다.</p>
</blockquote>
<p>프로그램을 실행하면 OS가 디스크에 있는 프로그램을 메모리에 로드한다. 메모리에 로드한 프로그램을 프로세스(process)라고 하며, CPU가 처리한다. 
CPU는 하나의 프로세스만 처리 가능해, 멀티 프로세스 환경에서는 OS가 스케줄링을 통해 CPU에 프로세스를 할당한다.</p>
<p>1.1.4 커널과 시스템 콜</p>
<ul>
<li>커널(kernel) : OS의 핵심 요소로, 컴퓨터 하드웨어와 프로세스의 보안, 자원 관리, 하드웨어 추상화 같은 중요한 역할을 수행. 자원 관리를 위헤 CPU 스케줄링, 메모리 관리, 입출력 관리, 파일 시스템 관리 등을 담당.</li>
</ul>
<p>운영 체제는 커널에서 관리하는 중요 자원에 사용자가 쉽게 접근하지 못하도록 커널 모드(kernel mode)와 사용자 모드(user mode)를 나눈다.</p>
<blockquote>
<p>커널 모드(kernel mode) : 하드웨어에 직접 접근해 메모리, CPU 같은 자원 사용
사용자 모드(user mode) : 커널 모드의 자원에 접근할 수 없다. 사용자 모드에서 실행된 프로세스가 자원에 접근하려면 시스템 콜을 호출해 커널에 요청해야 한다.
시스템 콜(system call) : 사용자 모드에서 커널 모드에 접근해 필요한 기능을 수행할 수 있게 하는 시스템 함수</p>
</blockquote>
